# bolttree

Bolt CSV/TSV tree tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/bolttree/

## Install / run

```bash
git clone https://github.com/theworker02/bolttree.git
cd bolttree
node src/cli.js
node --test
```
